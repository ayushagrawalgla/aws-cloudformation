# aws-cloudformation
# WEBSITE HOSTING ON AWS USING APPLICATION LOAD BALANCER AND CLOUDFORMATION

\# AWS CloudFormation: High-Availability Web Application behind ALB ## 📌 Project Overview This repository contains a declarative \*\*AWS CloudFormation (YAML)\*\* template that automates the deployment of a highly available, fault-tolerant web application infrastructure on AWS. ### 🏗️ Architecture Features \* \*\*Custom VPC (\`10.0.0.0/16\`)\*\* with Internet Gateway and Route Tables. \* \*\*Multi-AZ Public Subnets\*\* across two Availability Zones for high availability. \* \*\*Tiered Security Groups:\*\* Backend EC2 web servers accept HTTP (Port 80) traffic exclusively from the Application Load Balancer's Security Group. \* \*\*Dual EC2 Web Servers:\*\* Bootstrapped via \`UserData\` to launch Apache (\`httpd\`) with distinct landing pages to demonstrate round-robin load balancing. \* \*\*Application Load Balancer (ALB) &amp; Target Group:\*\* Dynamic health checks and automated traffic distribution. --- ## 📁 Repository Structure \* \`alb-website-template.yaml\` — Complete CloudFormation Infrastructure as Code (IaC) template. \* \`project-synopsis.pdf\` — Detailed 9-page technical implementation report and execution blueprint. --- ## 🚀 How to Deploy 1\. Log in to the \*\*AWS Management Console\*\* and open \*\*CloudFormation\*\*. 2\. Click \*\*Create stack\*\* -&gt; \*\*With new resources (standard)\*\*. 3\. Select \*\*Upload a template file\*\* and upload \`alb-website-template.yaml\`. 4\. Enter a Stack name (e.g., \`ALB-Website-Stack\`) and click \*\*Submit\*\*. 5\. Once status reaches \`CREATE\_COMPLETE\`, navigate to the \*\*Outputs\*\* tab and copy the \`ALBDnsName\` URL to access the site in your browser. --- ## 👥 Project Team \* \*\*2415800024\*\* — Ayush Agrawal \* \*\*12515990022\*\* — Mohit Pachauri \* \*\*2415001591\*\* — Soujanya Maity \* \*\*2415000703\*\* — Ishaan Varshney
